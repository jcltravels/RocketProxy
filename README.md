# RocketProxy — Support

This is the official support hub for **RocketProxy**, the proxy, VPN & network-tools app for iPhone, iPad, Mac, and Apple TV.

## Need help, found a bug, or have an idea?
- 🐞 **Report a bug:** [Open an issue](https://github.com/jcltravels/RocketProxy/issues/new)
- 💡 **Request a feature:** [Open an issue](https://github.com/jcltravels/RocketProxy/issues/new)
- ✉️ **Email us:** jcltravels@gmail.com

Please include your device, OS version, app version, and steps to reproduce.

## Quick start
1. Add a server (paste a URI, scan a QR, or import a config).
2. Pick a routing mode — Smart, Proxy Everything, or Local Only.
3. Tap **Connect**. On first connect, allow the VPN configuration.

## Protocols
Shadowsocks, ShadowsocksR, VMess, VLESS, Trojan, Hysteria, Hysteria2, TUIC, AnyTLS, WireGuard, SSH, Snell, Brook, Mieru, SOCKS5, HTTP/HTTPS.

## Privacy
We collect no data. Your traffic stays on your device. See the [Privacy Policy](https://jcltravels.co.uk/rocketproxy/privacy.html).
